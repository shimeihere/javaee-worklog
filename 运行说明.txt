周览 Worklog  运行 / 演示说明
==================================================

一、最省事：双击「运行Worklog.bat」
    它会依次做四件事：
      1) 检查 8080 端口是否被占（IDEA 里跑着同一个工程就会占住）
      2) 检查本机 MySQL(3306) 是否在跑
      3) 离线重新编译打包（约 10 秒，改过的代码自动生效）
      4) 启动服务
    启动后只需要记一个地址（前端和后端同一个端口，不再有 /api context-path）：
      打开浏览器  http://localhost:8080/        ← 直接进登录页
      接口根地址  http://localhost:8080/api     ← 所有接口统一 /api 前缀
      登录        POST /api/auth/login
                  请求体 {"username":"admin","password":"123456"}
    前端是单页应用：刷新 /workbench、/reports/daily 这些地址都能正常打开，
    不会 404（由后端做 index.html 兜底，见 WebMvcConfig）。
    停止：黑窗口里按 Ctrl+C，或直接关掉窗口。
    换端口：开始菜单搜 cmd，cd 到工程目录，执行  运行Worklog.bat 8081

二、在 IDEA 里跑（改代码调试时用）
    右上角运行配置选 WorklogApplication → Shift+F10
    若下拉里没有：打开 src/main/java/com/worklog/WorklogApplication.java，
    点 main 左边绿色三角跑一次，之后下拉里就有了。
    注意：IDEA 里跑着的时候 8080 被占，此时再双击 bat 会提示端口占用，属正常。

三、只打包（交作业 / 换机器演示）
    双击「打包Worklog.bat」→ 生成 target\worklog.jar 和 dist\worklog.jar
    这个 jar 自带 Tomcat，目标机器只要 JDK 17+：
        java -jar worklog.jar
        java -jar worklog.jar --server.port=8090           换端口
        java -jar worklog.jar --spring.datasource.password=xxx   改密码
    前端页面已经打进 jar（src/main/resources/static），所以 java -jar 之后
    直接访问 http://localhost:8080/ 就是完整系统，不需要再单独跑 npm。
    对方机器也要能连 MySQL，并且先执行 schema.sql 建库建表。

四、前端怎么改、怎么重新打进 jar
    改完前端代码后执行：
        cd frontend
        npm install           （第一次需要）
        npm run build         生成 frontend\dist
    然后把 frontend\dist 里的内容复制到 src\main\resources\static，
    再双击「打包Worklog.bat」即可。
    开发时也可以只用 npm run dev（5173 端口），它会把 /api 代理到 8080。

五、常见问题
    1) 提示端口 8080 已被占用
       → IDEA 里那个实例还在跑（红色方块停掉），或任务管理器结束 java.exe
       → 或换个端口：运行Worklog.bat 8081
    2) 报 Communications link failure
       → MySQL 没启动：管理员命令行 net start MySQL97
       → 或密码不对：application.yml 里 spring.datasource.password
    3) 改了代码没生效
       → 用「运行Worklog.bat」会自动重新打包；
         直接双击 target\worklog.jar 跑的是旧代码，别这么做
    4) 打开 http://localhost:8080 是 404 或白屏
       → 说明跑的是旧 jar（旧版本把 /api 当成了全局 context-path）。
         重新双击「运行Worklog.bat」打包启动即可；
         jar 里必须有 BOOT-INF/classes/static/index.html
    5) 控制台中文乱码（例如 闃诲欢鏂囦欢）
       → 日志按控制台代码页输出，默认 GBK(936)，与本机 cmd 一致；
         若你的终端是 UTF-8，先 set WORKLOG_CONSOLE_CHARSET=UTF-8 再启动

六、本机环境（换机器要相应改脚本里的两个路径）
    JDK 21    D:\jdkk
    Maven     D:\MAVEN\apache-maven-3.9.14-bin\apache-maven-3.9.14
    Maven 镜像 C:\Users\LS\.m2\settings.xml（阿里云；中央仓库本机连不上）
    数据库    MySQL97 服务，库 worklog，root/123456
    端口      8080，前后端同端口；接口统一 /api 前缀（无 context-path）
    打包产物   target\worklog.jar（内含 Tomcat、全部依赖与前端页面）
